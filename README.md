# XarxesGest

Plataforma autoallotjada (CloudPanel) per gestionar les xarxes socials de les marques de Soportic: calendari de publicació, adaptació per xarxa, publicació automàtica a LinkedIn, Instagram i X, IA (Claude per a textos i anàlisi, ChatGPT per a imatges), analítica i tendències.

Destinació: https://xarxesgest.soportic.es
